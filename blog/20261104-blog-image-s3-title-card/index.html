블로그 썸네일 만들기, 제목만 넣으면 나오는 코드 한 장과 세 번의 실패

✓ FIELD-TESTED

이 글 맨 위 이미지, 제가 그린 게 아니에요.
명령 한 줄에 제목과 부제를 넣었더니 나온 그림입니다.

python gen_title_card.py "블로그 썸네일 만들기, 제목만 넣으면 나오게" "Claude Code로 그리기, 연재 3편" 01_title.png

블로그 썸네일 만들기는 "제목을 받아서 대표 이미지를 그리는 코드" 한 개면 끝나요. 배경·로고·도장·글꼴은 코드에 고정해 두고, 바뀌는 건 제목과 부제뿐이라 글마다 같은 얼굴의 썸네일이 나옵니다.

다만 이 한 줄이 되기까지 세 번 넘어졌어요. 오늘은 그 세 번을 순서대로 보여 드릴게요.

연재 정리부터 할게요. 1편은 그림 툴 대신 Claude Code에게 파이썬(Pillow)으로 그리게 하는 방법, 2편은 색 규칙 파일로 톤을 맞추는 방법이었어요. 이번 3편이 마지막입니다.

1. 썸네일 코드는 어떻게 생겼나요?

고정 부분과 바뀌는 부분을 나눈 함수 하나예요. 제 썸네일 코드는 이렇게 생겼어요.

  • 고정: 900×470 크림 종이, 왼쪽 위 표식, 오른쪽 위 기울어진 도장, 아래 로고
  • 바뀌는 것: 제목(굵은 글꼴, 최대 3줄), 부제(빨간 손글씨 + 밑줄)
  • 규칙: 제목이 3줄이 되면 글자를 50에서 42로 줄인다

처음 만들 때는 이렇게 시키면 돼요.

블로그 대표 이미지를 만드는 gen_title_card.py를 만들어 줘.
사용법은 python gen_title_card.py "제목" "부제" 출력.png
크기 900x470, 색과 글꼴은 style.py 것만 쓰고,
제목은 왼쪽 정렬 최대 3줄, 넘치면 글자 크기를 줄여.

2편의 색 규칙 파일을 불러 쓰게 하는 게 중요해요. 그래야 썸네일과 본문 그림이 한 사람 것처럼 보입니다.

2. 첫 번째 실패, 단어가 두 줄로 찢어져요

한글 제목을 글자 단위로 자르면 단어 중간에서 줄이 바뀌어요. 띄어쓰기 기준으로 잘라야 합니다.

예전 썸네일 코드는 글자를 하나씩 붙여 가다 폭을 넘으면 줄을 바꿨어요. 영어는 단어 사이에 공간이 많아 덜 티 나는데, 한글 제목에선 바로 보입니다.

오늘 두 방식을 같은 제목으로 돌려 봤어요.

"실패가"가 "실패 / 가"로 갈라졌죠. 지금 코드는 띄어쓰기 단위로 넣다가, 단어 하나가 한 줄보다 길 때만 글자 단위로 자릅니다.

def wrap(d, text, font, maxw, limit=3):
    lines, cur = [], ""
    for word in text.split(" "):                 # 띄어쓰기 단위로
        cand = (cur + " " + word) if cur else word
        if d.textlength(cand, font=font) <= maxw:
            cur = cand
            continue
        if cur:
            lines.append(cur)
        cur = word                               # (실제 코드엔 너무 긴 단어 처리가 더 있어요)
    if cur:
        lines.append(cur)
    return lines[:limit]

3. 두 번째 실패, 부제 기호가 빈칸으로 찍혀요

손글씨 글꼴엔 가운뎃점(·), 줄표(—), 화살표(→), 체크(✓) 같은 기호가 없는 경우가 많아요. 없는 글자는 에러 없이 빈칸으로 찍힙니다.

제 썸네일 부제는 나눔손글씨 펜 글꼴이에요. 오늘 이 글꼴 파일에 어떤 글자가 들어 있는지 직접 확인해 봤더니, 쉼표는 있고 · — → ✓ ↑ 다섯 개는 없었어요. 그대로 찍으면 이렇게 됩니다.

에러가 안 나서 더 위험해요. 코드는 "완료"라고 하는데 그림엔 구멍이 나 있거든요.

그래서 썸네일 코드에 치환 한 줄을 넣었어요.

for a, b in (("·", ","), ("—", ","), ("–", ","), ("↑", ""), ("∧", "")):
    subtitle = subtitle.replace(a, b)

본문 그림의 화살표는 2편에서 말한 것처럼 글자가 아니라 선으로 그리고요.

4. 세 번째 실패, 영어와 한글 높이가 어긋나요

글꼴이 다른 영어와 한글을 한 줄에 놓으면 글자 바닥선이 안 맞아요. 같은 글꼴 계열을 쓰고, 세로 위치를 "가운데 기준"으로 맞추면 해결돼요.

제 블로그엔 썸네일 위쪽에 검은 띠를 두르는 종류가 하나 있어요. 띠 안에 영어 이름과 한글 이름을 나란히 넣었는데, 처음 나온 그림에서 두 이름의 줄이 안 맞는 게 보여서 다시 시켰습니다. 영어는 고정폭 글꼴, 한글은 다른 글꼴이라 글자 바닥선이 서로 달랐던 거예요.

고친 방법은 두 가지였어요.

  • 영어도 한글과 같은 글꼴 계열(Pretendard)로 바꿈
  • 글자를 놓을 때 기준점을 "왼쪽-가운데"(anchor="lm")로 지정해서, 글자 크기가 달라도 세로 가운데가 같은 선에 오게 함
d.text((x, cy), "NEXT FIELD", font=f_en, fill=PAPER, anchor="lm")
d.text((x2, cy), "미래기술 지도", font=f_ko, fill=PAPER, anchor="lm")

5. 그림을 받으면 무엇을 보나요?

글자가 찢어졌는지, 빈칸·네모가 있는지, 빨강이 한 곳인지 세 가지만 봐요. 이 연재에서 나온 실패가 전부 이 세 개 중 하나였어요.

1편에서 말한 것처럼 저도 이 연재 그림을 만들면서 2번에 또 걸렸어요. 그래서 이 세 개는 규칙이라기보다 습관에 가까워요. 파일을 열고, 3초 보고, 걸리면 말로 다시 시킵니다.

자주 묻는 질문

Q. 블로그 썸네일 만들기, 제목이 너무 길면 어떻게 되나요?
제 코드는 3줄까지만 쓰고 글자를 줄여요. 그래도 넘치면 잘리니까, 그땐 제목을 줄이는 게 맞습니다. 썸네일에서 4줄짜리 제목은 어차피 안 읽혀요.

Q. 썸네일마다 디자인을 다르게 하고 싶으면요?
코드에 "종류" 값을 하나 받게 하면 돼요. 제 썸네일도 일반 글은 빨간 도장, 미래 기술을 다루는 글은 검은 띠와 검은 도장으로 나뉘는데, 같은 코드에 값 하나만 다르게 넘깁니다.

Q. 코드를 하나도 몰라도 되나요?
이 연재에 나온 코드는 전부 Claude Code가 짰어요. 제가 한 건 "무엇을 그릴지 말하기"와 "결과 그림 열어 보기"였습니다. 코드는 읽을 줄 몰라도 그림은 누구나 볼 수 있으니까요.

연재 세 편을 한 줄로 줄이면 이거예요. 그림은 코드로 남기고, 색은 파일 하나에 정하고, 결과는 반드시 눈으로 봅니다.
