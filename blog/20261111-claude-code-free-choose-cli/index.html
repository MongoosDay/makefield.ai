AI 오답 노트2026-11-11

클로드 코드 무료 안 될 때, GPT·Gemini 셋 중 무료로 시작할 AI 고르기

✓ FIELD-TESTED

블로그 글을 보고 클로드 코드를 깔았어요.
claude를 치고, 브라우저가 열리고, 평소 쓰던 무료 Claude 계정으로 로그인했어요.
그런데 거기서 더 나가질 않습니다.

먼저 답부터 드릴게요. 클로드 코드는 무료 claude.ai 계정으로는 쓸 수 없고, Pro 이상 유료 요금제나 API(Console) 계정이 있어야 합니다. 돈 내기 전에 맛부터 보고 싶다면 ChatGPT 무료 계정으로 되는 Codex CLI나, 구글 개인 계정으로 되는 Antigravity CLI(agy)로 시작하면 돼요. (2026년 11월 공식 문서 기준)

지난 편에서는 검은 창에서 외울 명령어 6개를 정리했어요. 이번 편은 그 창에서 부를 AI를 고릅니다.

저는 15년째 제조 현장에서 설비 제어를 해 온 엔지니어고, AI를 3년 가까이 써 왔어요. 지금 주력은 클로드 코드고, 다른 회사 도구도 써 봤습니다.

1. 클로드 코드 무료 계정으로는 왜 안 되나요?

클로드 코드는 처음부터 무료 플랜에 들어 있지 않은 도구예요. 로그인 오류가 아니라 요금제 조건이라서, 다시 깔거나 재로그인해도 안 풀립니다.

공식 설치 문서에 이렇게 적혀 있어요.

Claude Code requires a Pro, Max, Ultra, Team, Enterprise, or Console account.
The free claude.ai plan does not include Claude Code access.

"무료 claude.ai 플랜은 클로드 코드를 포함하지 않는다"는 거죠(code.claude.com 설치 문서, 2026-11-11 확인).

여기서 제가 진짜 데인 건 도구가 아니라 정보의 날짜였어요.
올해 6월, 새 모델이 나왔을 때 그 모델에 대해 AI한테 물었거든요. AI가 검색도 안 하고 단정한 답을 세 번 연달아 틀렸어요. 결국 웹 검색으로 공식 문서를 한 줄씩 대조해서 지원 여부, 필요한 버전, 요금제 조건을 다시 정리했습니다.
10월엔 지인이 "AI 뭐 결제해야 돼?"라고 물어서 추천을 정리했는데, 이번엔 AI 답 옆에 "가격은 6월 지식 기준, 미검증" 딱지를 붙여서 넘겼어요. 한 번 데인 뒤로 생긴 습관이에요..

그래서 지금 원칙은 하나예요. 요금·지원 여부는 AI 답이든 블로그 글이든 날짜부터 보고, 결제 직전엔 공식 문서로 한 번 더 확인합니다. 이 분야는 반년이면 판이 바뀌거든요.

2. GPT·Claude·Gemini CLI, 무료로 되는 건 어디까지?

세 도구 중 무료로 시작할 수 있는 건 Codex CLI(ChatGPT 계정)와 Antigravity CLI(구글 계정) 두 개고, 클로드 코드는 Pro 월 $20부터예요. 셋 다 "검은 창에서 내 폴더를 직접 읽고 쓰는 AI", 즉 CLI 에이전트라는 점은 같습니다.

항목Codex CLIClaude CodeAntigravity CLI
부르는 이름codexclaudeagy
로그인 계정ChatGPT 계정Claude 계정구글 계정
무료로 시작가능불가가능(주간 한도)

규칙 메모 파일AGENTS.mdCLAUDE.mdAGENTS.md 또는 GEMINI.md

요금은 2026년 9월 기준 각 회사 공식 문서 값이에요. 월 단위고, 수시로 바뀝니다.

표에 Gemini CLI가 아니라 Antigravity CLI가 있는 이유도 짚을게요. 구글 개발자 블로그 공지에 따르면 2026년 6월 18일부터 무료 사용자와 Google AI Pro·Ultra 개인 구독자는 Gemini CLI 요청이 막히고, 새 도구 Antigravity CLI(agy)로 옮겨 갔어요. 그 전에 쓰인 "Gemini CLI 무료로 쓰기" 글을 따라 하면 똑같이 진행이 안 됩니다.

3. 셋 중 무엇을 고를까 — 조건으로만 갈라요

성능 순위는 몇 달이면 뒤집히니, 지금 내 조건으로 고르는 게 제일 오래 맞아요.

  1. 이미 ChatGPT를 쓴다 → Codex CLI. 같은 계정으로, 무료 계정으로도 맛볼 수 있어요.
  2. 돈 내기 전에 나한테 맞는지부터 보고 싶다 → Codex CLI 또는 Antigravity CLI.
  3. 이 연재 화면을 그대로 따라 하고 싶다 → 클로드 코드. 대신 Pro부터예요.
  4. 구글 계정 하나로 여러 회사 모델을 골라 쓰고 싶다 → Antigravity CLI.

여러분은 지금 어느 줄에 해당하세요? 둘 이상 걸리면 이미 돈을 내고 있는 쪽이 정답일 때가 많아요.

4. 따라하기: 30분, 같은 부탁을 두세 도구에 시켜 보기

표만 보고 골라도 되지만, 30분이 있으면 내 문서로 직접 시켜 보는 게 제일 확실해요. 비교만 해볼 거면 무료로 되는 Codex와 Antigravity 둘만 해도 됩니다.

1단계. 재료를 똑같이 준비합니다.
공개돼도 괜찮은 문서 서너 개(회의 메모, 지난달 일지)를 고르고, 거래처 이름·단가가 든 건 빼요. 그리고 폴더를 도구 수만큼 만들어 같은 파일을 복사합니다.

C:\ai-work\
 ├─ test-codex\   ← 같은 문서 4개
 ├─ test-claude\  ← 같은 문서 4개
 └─ test-agy\     ← 같은 문서 4개

2단계. 글자 하나 안 바꾸고 같은 부탁을 합니다.
각 폴더로 cd 해서 codex·claude·agy 중 하나를 부르고, 아래 문장을 그대로 붙여 넣어요. 처음엔 브라우저 로그인 창이 뜹니다.

이 폴더에 있는 문서를 전부 읽고, 각 문서에서 결정된 사항과 담당자, 기한을 표로 정리해서 summary.md 파일로 저장해줘. 문서에 없는 내용은 지어내지 말고 "문서에 없음"이라고 적어줘.

3단계. 느낌 말고 칸으로 채점합니다.

확인 항목도구 A도구 B
summary.md가 실제로 생겼나 (탐색기 확인)
원문에 없는 내용을 지어낸 곳 (개수)
빠뜨린 결정 사항 (개수)
내가 손으로 고친 줄 수

둘째 줄은 원문을 옆에 펴놓고 대조하세요. 그럴듯하게 틀린 줄이 제일 비싸거든요.

이긴 도구는 메모 한 장에 적어 둡니다. 다시 볼 날짜까지요.

설명은 클로드 코드 기준이지만, 폴더로 이동해 부르고 같은 문장으로 시키는 이 방식은 GPT(Codex CLI)와 구글(Antigravity CLI, 예전 Gemini CLI)에서도 똑같이 됩니다. 설치는 클로드 코드 설치 편에 적어 뒀어요.

자주 묻는 질문

Q. 클로드 코드 무료체험은 없나요?
2026년 11월 공식 설치 문서 기준으로 무료 claude.ai 플랜은 클로드 코드를 포함하지 않아요. 결제 전에 써 보고 싶으면 무료로 되는 Codex CLI나 Antigravity CLI로 위 4번 비교를 먼저 해 보세요.

Q. 셋을 다 결제해서 같이 쓰면 안 되나요?
권하지 않아요. 규칙 메모와 습관이 한 도구에 쌓여야 층이 올라가요. 하나로 시작하고, 메모에 적은 날짜에 다시 보면 됩니다.

Q. 나중에 갈아타면 쌓은 규칙은 버려야 하나요?
아니요. 도구마다 읽는 규칙 파일 이름이 달라서 생기는 문제라, 파일만 옮기면 돼요. 이건 2부 지침 파일 편에서 따로 다룹니다.
